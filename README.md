# 体重秤机构模型

## 夹爪 · W45

蓝盘中心基圆从 Ø131 扩到 Ø156 mm，外包络仍是 228 × 228 mm。保留 W44 的四爪止挡、蓝盘跨接和绿盘滚轮观察窗。每爪工作行程仍为 10.09 mm；向外的额外 8 mm 是蓝盘与单爪的几何余量，不是现有联动行程。

- [下载 W45 试打印包](W45/W45_Gripper_Trial_Package.zip)（Blender、STL、对比图和试打说明）
- [查看 W45 孔位对照表](W45/Hole_Dimensions.md)

新蓝盘已无支撑试切，尚未实物试装或做承载测试。W44 绿盘和标准白爪可以沿用；包里的备用白爪只供后续试验。
